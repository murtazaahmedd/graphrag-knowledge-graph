# Dashboards

The Revenue Dashboard shows monthly recurring revenue, churn and expansion.
The Revenue Dashboard reads from the Billing Service.
The Revenue Dashboard is owned by the Analytics Team.

The Usage Dashboard shows active workspaces and feature adoption.
The Usage Dashboard reads from the Usage Service.
The Usage Dashboard is owned by the Analytics Team.

The Support Dashboard shows ticket volume and first response time.
The Support Dashboard reads from the Ticket Service.
The Support Dashboard is owned by the Support Tools Team.
